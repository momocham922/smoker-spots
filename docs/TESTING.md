# 実機テスト手順

このドキュメントでは、喫煙所マップアプリを実機でテストする方法について説明します。

## 前提条件

- Expoアカウント（[https://expo.dev/signup](https://expo.dev/signup)で登録可能）
- iOS/Androidデバイス
- Expo Goアプリ（[App Store](https://apps.apple.com/app/apple-store/id982107779)または[Google Play](https://play.google.com/store/apps/details?id=host.exp.exponent)からダウンロード）

## 開発版のテスト

開発中のアプリをテストするには、以下の手順に従ってください：

1. プロジェクトディレクトリで開発サーバーを起動します：

```bash
cd smoker-spots
./run-app.sh
```

2. 表示されたQRコードをスキャンします：
   - **iOS**: カメラアプリでQRコードをスキャン
   - **Android**: Expo GoアプリでQRコードをスキャン

3. Expo Goアプリが自動的に開き、アプリがロードされます。

## ビルド版のテスト

ビルドされたアプリをテストするには、以下の手順に従ってください：

### 1. ビルドの作成

```bash
cd smoker-spots
./build-native.sh [platform] preview
```

`[platform]`は`ios`、`android`、または`all`のいずれかを指定します。

### 2. ビルドの確認

ビルドが完了すると、Expoダッシュボードにビルドが表示されます：
[https://expo.dev/accounts/[your-username]/projects/smoker-spots/builds](https://expo.dev/accounts/[your-username]/projects/smoker-spots/builds)

### 3. テスト用アプリのインストール

#### iOS

1. Expoダッシュボードからビルドを選択
2. 「Install」ボタンをクリック
3. 表示されたQRコードをiOSデバイスのカメラでスキャン
4. 指示に従ってプロファイルをインストール

#### Android

1. Expoダッシュボードからビルドを選択
2. 「Download」ボタンをクリックしてAPKをダウンロード
3. APKファイルをAndroidデバイスに転送
4. APKファイルをタップしてインストール（「提供元不明のアプリ」のインストールを許可する必要があります）

## テスト項目

アプリをテストする際は、以下の機能が正常に動作することを確認してください：

1. **スプラッシュ画面**
   - アニメーションが滑らかに再生されるか
   - 適切な時間でメイン画面に遷移するか

2. **認証**
   - ログイン/登録画面が正しく表示されるか
   - 認証プロセスが正常に機能するか

3. **マップ画面**
   - 地図が正しく表示されるか
   - 現在地が取得できるか
   - マーカーが表示されるか
   - マーカーをタップすると詳細情報が表示されるか

4. **リスト画面**
   - 喫煙所の一覧が表示されるか
   - 検索機能が正常に動作するか
   - カードをタップすると詳細画面に遷移するか

5. **詳細画面**
   - 喫煙所の詳細情報が正しく表示されるか
   - お気に入り登録/解除が機能するか

6. **プロフィール画面**
   - ユーザー情報が表示されるか
   - ログアウト機能が正常に動作するか

## 問題の報告

テスト中に問題が発生した場合は、以下の情報を含めて報告してください：

1. デバイスの種類とOSバージョン
2. 問題が発生した画面と操作
3. エラーメッセージ（表示された場合）
4. 問題を再現する手順
5. スクリーンショット（可能であれば）

問題の報告は、GitHubのIssuesまたはメールで行ってください。
